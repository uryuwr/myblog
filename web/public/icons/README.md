# PWA 图标说明

需要在此目录放置以下图标文件：

1. `icon-192.png` - 192x192 像素的 PNG 图标
2. `icon-512.png` - 512x512 像素的 PNG 图标

## 推荐工具

可以使用以下工具生成图标：
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

## 临时方案

可以使用 vite.svg 转换为 PNG，或者使用在线工具如：
- https://svgtopng.com/

图标应该使用深色背景 (#0D0D15) 配合青色 (#00D9FF) 的设计风格。
